# Admin 登录表单轻量控件视觉优化计划

## 1. 当前状态和结果

- 当前状态：已结束
- 结果：已完成；输入内容、placeholder 和按钮文字统一使用 `14px / 400`，低对比细边框与浅蓝按钮保持不变，Admin typecheck、lint 与 Markdown lint 通过，浏览器验证按用户要求未执行。

## 2. 关联需求

- `BASE-ADMIN-002`：提供管理员登录与权限入口。

## 3. 背景

登录页两个输入框当前使用有色背景、较明显边框和内阴影，视觉边界偏重；登录按钮使用 Ant Design 默认深蓝背景和 `600` 字重。用户希望输入框更轻、占位文本不加粗，并降低按钮背景和文字的视觉重量。

## 4. 目标

1. 将输入框默认边界调整为视觉更细的低对比度 `1px` 边框并移除内阴影。
2. 将输入框占位文字字重明确设置为 `400`。
3. 将登录按钮文字字重调整为 `400`。
4. 使用浅蓝背景和深蓝文字保持主操作辨识度与文字对比度。
5. 将输入内容、placeholder 和按钮文字从 `16px` 调整为 `14px`，进一步降低视觉重量。

## 5. 非目标

1. 不完全移除输入框的 hover 和键盘焦点边界。
2. 不修改输入框高度、圆角、图标、占位文案和校验逻辑。
3. 不修改按钮尺寸、提交行为和加载状态。

## 6. 现状分析

- 输入框边框颜色为 `rgba(196, 208, 221, 0.62)`，并带有内阴影。
- 输入框占位文本没有显式字重，可能受外层样式影响。
- 登录按钮只覆盖尺寸、圆角、字号、`600` 字重和阴影，背景由 Ant Design 默认主蓝提供。

## 7. 方案设计

1. 输入框默认边框改为 `rgba(71, 84, 103, 0.12)`，背景改为半透明白色并移除内阴影。
2. hover 使用低透明度主蓝边框；focus 保留浅蓝边框和 `2px` 低透明度焦点环，保证键盘可见性。
3. 占位文本明确使用 `font-weight: 400`。
4. 登录按钮使用 `#E6F4FF` 背景、`#BAE0FF` 边框和 `#0958D9` 文字，hover 加深至 `#BAE0FF`。
5. 登录按钮文字字重设为 `400`，阴影同步减弱。
6. 输入框实际内容、placeholder 与按钮文字统一使用 `14px / 400`，保持输入前后的排版一致。
