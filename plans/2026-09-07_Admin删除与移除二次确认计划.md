# Admin 删除与移除二次确认计划

## 当前状态和结果

- 状态：已结束
- 结果：已完成；本地实现、文档同步和轻量门禁通过，重型验证按项目策略未执行。

## 目标与授权

- 关联需求：`BASE-ADMIN-004`、`BASE-ADMIN-007`、`BASE-ADMIN-008`。
- 用户于 2026-09-07 要求检查管理端全部页面，所有单条和批量删除、移入回收站及移除操作必须二次确认，并补齐提交防重与失败反馈，同步规则文档。
- 本计划覆盖页面盘点、共享确认组件、缺失入口接入、回归用例及文档同步。已有合规确认保留，不叠加第三次确认。
- 非目标：新增删除能力、改变后端权限和数据生命周期、修改 Web、依赖升级、提交推送、发布部署或重型验证。
- 待确认问题：无。

## 现状与方案

| 模块 | 现状 | 实施动作 |
| --- | --- | --- |
| 用户 | 单条与批量删除共用原因表单，但缺少明确风险说明、完整提交锁 | 接入标准确认弹窗，保留原因与失败选择，确认后调用原批量端点 |
| 角色权限 | 单条与批量硬删除已有标准确认和失败反馈 | 保留页面流程，通过公共组件增强防重与关闭保护 |
| 文件资产 | 单条与批量硬删除已有标准确认和失败反馈 | 保留页面流程，通过公共组件增强防重与关闭保护 |
| 系统设置 | LOGO 移除直接调用接口 | 增加确认，固定确认时 revision，提交互斥，失败保留 LOGO 与草稿 |
| 管理员 | 移除头像直接修改编辑草稿 | 增加确认后清空草稿，继续保存后生效，保存期间防重及禁止关闭；通过上传控件状态回调与上传互斥 |
| 个人设置、欢迎、登录、安全日志、系统状态 | 无删除、移入回收站或移除入口 | 保留现有功能；日志继续只读 |

筛选清空、取消选择、权限勾选和启停等现有非删除操作保持原交互。二次确认表达操作者意图，服务端权限、CSRF、事务和审计保持原边界。

## 风险与回滚

- 公共弹窗影响角色与资产既有确认流程，必须保留成功关闭、失败可重试和已选范围。
- 头像移除只修改草稿；不提前请求后端或丢失同时编辑的显示名称。
- LOGO 使用确认时的 revision；冲突要求取消并加载最新配置后重新确认，避免静默删除其他管理员新上传的 LOGO。

## 实施结果

- 已按 `config/routes.ts` 盘点 10 个实际路由页面，并交叉搜索全部 Feature、共享上传控件及 API 删除调用；删除与移除入口分布在用户、角色、资产、系统设置和管理员页面，其他页面无此类入口。
- 公共弹窗在异步校验前同步加锁，确认 Loading 与禁用状态覆盖整个回调，提交中禁止取消、关闭、遮罩及 Esc，捕获并展示未由页面处理的失败；角色与资产保留既有确认和错误提示。
- 用户单条与批量删除使用同一标准弹窗，保留可选原因和原批量 API；只在确认后写入，失败保留原因和选择。
- LOGO 移除增加确认、版本快照与站点写入互斥；失败保留预览和草稿，冲突要求加载最新配置并重新确认。
- 管理员头像移除先确认后修改编辑草稿，保存仍一次提交头像及其他资料；保存防重、失败内联提示和上传互斥保留草稿一致性。
- 补充公共弹窗取消、防重、提交中关闭和失败重试用例；更新用户单批删除、头像取消与保存、LOGO 取消与失败重试及版本冲突用例。用例已通过类型与 lint，Vitest 未执行。
- 已同步 `apps/admin/AGENTS.md`、`docs/PROJECT_REQUIREMENTS.md`、Admin 工程标准、认证授权架构、系统设置架构以及 ADR 0010、0011。文件资产架构与 ADR 0012 的硬删除确认说明仍准确；根规则、开发通用流程、文档索引和测试策略已有适用入口，未重复加入专题全文。历史计划与旧 Changelog 保留当时事实，新规则以当前标准和本次 Changelog 为准。
