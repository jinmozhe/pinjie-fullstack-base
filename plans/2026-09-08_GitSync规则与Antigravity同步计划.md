## 状态与结果

- 状态：已结束
- 结果：已完成；Antigravity 技能与母版规则已同步，技能及轻量治理检查通过，未执行实际 Git 交付。
- 关联需求：无。本次同步跨项目 Git 授权与验证规则，不修改产品能力。

## 目标与范围

- 以已确认的个人 git-sync 技能和导航项目相关规则为来源，同步全仓本地可交付内容授权、同一错误三次失败中止、Security 仅在线上执行。
- Antigravity 全局技能按其已安装官方说明定位到 `~/.gemini/config/skills/git-sync/SKILL.md`；同步前核对原有规则，保留恢复保护、精确暂存、平台审批及远端门禁。
- 更新母版根规则、开发流程、GitHub 工作流说明、文档索引与 Changelog；本计划及两个索引记录母版此次同步。
- 不复制导航产品需求、项目阶段、业务计划或发布事实，不修改源码、依赖、工作流、Ruleset，不执行本地 Security、重型验证或 Git 交付。

## 约束与冲突处理

| 来源 | 适用约束 | 落实与验证 |
| --- | --- | --- |
| 用户已确认的新规则 | 一次调用覆盖本仓库全部本地分支、提交和可交付改动，不重复确认 Git 授权 | 根规则、开发流程第 18.1 节、Antigravity 技能逐项核对 |
| 用户三次上限 | 同一根因三次实际修复或恢复后仍失败即中止，保留记录并等待用户决策 | 计数跨分支、PR、提交和技能重入，不以初次发现或只读查询凑数 |
| 用户 Security 边界 | 本地不扫描、不安装扫描器、不通过 Docker 或 WSL 代跑，不建立统一 pnpm 前置命令 | 工作流说明第 9.9 节与技能；既有轻量检查及提交秘密核对保留 |
| 母版根规则与开发流程第 17 节 | 先登记计划、保护原文、按实际影响验证 | 原字节备份、写前哈希、逐文件复读、文档治理门禁 |
| 母版原有条款 | 当前任务限定、失败即停止、仅快进同步与新规则冲突 | 就地替换适用条款；保留独立发布授权、重型验证限制、Wiki 关闭和既有生产链路 |

## 实施步骤与恢复

1. 核对两仓库和目标技能原文、母版工作区、索引与计划规则，准备逐项差异。
2. 先登记母版计划及两个索引；保存准确目标的原字节副本和哈希，准备全部候选内容。
3. 通过准确工具审批写入工作区外目标，写前核对全部原文未变化，逐文件写后复读及校验。
4. 验证技能格式、Markdown、文本、文档治理、工作区与模块边界，核对仅有授权文档变化。
5. 完成后回写计划和索引，清理已确认归属的临时文件；需撤回时仅针对本次差异恢复，保留后续用户修改和永久计划。
