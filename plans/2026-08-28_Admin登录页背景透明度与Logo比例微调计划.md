# Admin 登录页背景透明度与 Logo 比例微调计划

## 1. 当前状态和结果

- 当前状态：已结束
- 结果：已完成；背景彩色层透明度整体降低约三分之一，Logo 从 `36px` 放大二分之一至 `54px`，Admin typecheck、lint 与 Markdown lint 通过，浏览器验证按用户要求未执行。

## 2. 关联需求

- `BASE-ADMIN-002`：提供管理员登录与权限入口。

## 3. 背景

上一轮已将登录页背景升级为蓝、青、品牌红三色宽幅渐变，并将 Logo 调整为 `36px` 扁平深红 SVG Mask。用户反馈背景色彩偏重，同时希望 Logo 放大二分之一。

## 4. 目标

1. 将现有背景彩色层透明度整体降低约三分之一。
2. 保留多色层次，避免退回最初接近纯白的效果。
3. 将 Logo 从 `36px` 精确放大至 `54px`，保持等比例和固定布局尺寸。

## 5. 非目标

1. 不改变渐变方向、颜色种类或静态呈现方式。
2. 不修改 Logo 轮廓、深红色值和原始品牌资产。
3. 不修改登录表单、认证、会话说明和忘记密码交互。

## 6. 现状分析

- 背景主蓝、品牌红和青色层最高透明度分别为 `13%`、`9%` 和 `7.5%`。
- 综合色带蓝、青和品牌红透明度分别为 `6.5%`、`5.5%` 和 `5%`。
- 登录页 Logo 当前固定为 `36px`。

## 7. 方案设计

1. 主背景蓝色最高透明度调整为 `9%`，品牌红调整为 `6%`，青色调整为 `5%`。
2. 综合色带蓝、青、品牌红分别调整为 `4%`、`3.5%` 和 `3.2%`。
3. Logo 宽、高和 Flex 基准同步从 `36px` 调整为 `54px`，避免布局尺寸不一致。
4. 保留 `--login-brand-red` Token 和 SVG Mask 实现。
