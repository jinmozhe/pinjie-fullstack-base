# Admin 登录页面高质感重新设计计划

## 1. 当前状态和结果

- 当前状态：已结束
- 结果：已完成；Admin `/login` 页面重构升级为 Ant Design 6 极简微质感规范，Admin typecheck、lint 及 Markdown lint 全量通过

## 2. 关联需求

- `BASE-ADMIN-AUTH`：Admin 管理端身份认证与会话管理

## 3. 背景

当前 Admin 管理端登录页面结构完整，但在视觉层次、品牌呈现和细节微质感上较为基础。结合 Ant Design 6 / Ant Design Pro 的设计体系与浅色高质感规范，由 UX 架构师、UI 设计师与前端开发专家协同对 `/login` 页面进行重构升级。

## 4. 目标

1. 基于方案一（Pro 经典极简微质感），为 Admin `/login` 页面构建高质感品牌与表单呈现。
2. 保持与现有 Umi Max、TanStack Query Mutation 会话流、HTTP 错误处理管道的完整一致性。
3. 严格保护既有 Vitest 单元测试（`StageC.test.tsx`）及 E2E 测试契约，确保无破坏性变更。
4. 保证 WCAG AA 可访问性与移动端/桌面端流畅自适应。

## 5. 非目标

1. 不修改后端认证接口（`/api/admin/auth/login` 等）或会话数据结构。
2. 不引入额外的第三方庞大 UI 依赖，沿用 Ant Design 6 与现有一致的技术栈。
3. 不变更 Web 端的登录流程。

## 6. 现状分析

`apps/admin/src/features/auth/LoginPage.tsx` 目前使用标准的 Ant Design `Form` 与原生类名排版，功能健全但背景与卡片视觉略显单一，缺少现代科技光感、多层漫反射投影和安全信任指示。

## 7. 方案设计

1. **背景环境**：升级 `.login-screen` 样式，引入浅灰白底色与品牌蓝紫渐变光斑（Ambient Mesh Glow）。
2. **悬浮卡片**：使用细腻的白底微投影卡片（`max-width: 400px`），双层漫反射投影与浅灰细边框。
3. **品牌与表单**：
   - 居中盾牌图标微徽章（`SafetyCertificateOutlined`）与蓝渐变背景。
   - 保留 `label="用户名"`、`label="密码"` 确保可访问性测试通过。
   - 增加输入框图标前缀、占位引导与焦点光晕。
   - 底部增加会话安全指示。
4. **错误反馈**：`Alert` 错误提示带图标和淡入反馈。
