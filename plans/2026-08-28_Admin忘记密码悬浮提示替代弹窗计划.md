# Admin 忘记密码悬浮提示替代弹窗计划

## 1. 当前状态和结果

- 当前状态：已结束
- 结果：已将忘记密码点击弹窗替换为浅灰色悬浮提示，并保留键盘聚焦可访问性。

## 2. 关联需求

- `BASE-ADMIN-002`：提供管理员登录与权限入口。

## 3. 背景

登录页“忘记密码？”当前是蓝色链接按钮，点击后打开带双色安全图标的提示弹窗。用户希望降低该入口的视觉重量，并取消点击交互，改为鼠标悬停直接提示联系超级管理员。

## 4. 目标

1. 将“忘记密码？”改为浅灰色只读提示入口。
2. 鼠标悬停时显示“请联系超级管理员为您重置密码”。
3. 支持键盘聚焦显示同一 Tooltip，保留非鼠标用户可用性。
4. 删除不再需要的弹窗、状态、图标和样式代码。

## 5. 非目标

1. 不增加密码找回、邮件或手机验证能力。
2. 不保留点击后弹窗行为。
3. 不修改登录提交、会话提示和其他表单逻辑。

## 6. 现状分析

- 页面使用 `recoveryOpen` 状态控制 Ant Design `Modal`。
- “忘记密码？”由 `Button type="link"` 触发，默认使用主蓝色。
- 弹窗使用 `SafetyCertificateTwoTone` 和三组专属 CSS。
- Tooltip 已由 Ant Design 提供，无需增加依赖。

## 7. 方案设计

1. 使用 Ant Design `Tooltip` 包裹可聚焦 `span`，提示文案为“请联系超级管理员为您重置密码”。
2. 触发文本使用 `#98A2B3` 浅灰色，hover 和 focus 调整为 `#667085`。
3. 使用 `cursor: help` 表达该元素提供说明信息，不呈现可点击按钮语义。
4. 删除 `recoveryOpen`、`Modal`、`SafetyCertificateTwoTone` 和原弹窗 JSX/CSS。
5. 保留 `tabIndex={0}`，让键盘用户可以触发 Tooltip。
