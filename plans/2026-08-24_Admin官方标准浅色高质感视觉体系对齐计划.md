# Admin 官方标准浅色高质感视觉体系对齐计划

## 当前状态和结果

- 状态：已结束
- 结果：已完成

## 关联需求

- BASE-011（管理控制台操作界面与交互体验）
- BASE-004（管理端 RBAC、会话与安全日志呈现）

## 背景

当前管理端采用深色侧栏与饱和度较高的选中色块，顶部缺少完整的 Header 导航与操作区。ProTable 被关闭原生工具条并使用手写工具栏，页面视觉层级与官方 Ant Design Pro v6 标准存在差距。

## 目标

1. 将 ProLayout 切换为官方标准浅色侧栏与白色 Header，完善头像和账号操作区。
2. 恢复 ProTable 的刷新、密度、全屏和列设置工具，并将主操作放入 `toolBarRender`。
3. 统一 PageContainer、工作面板、微边框、轻投影和浅灰工作区层级。
4. 修复 Footer 布局和不同视口下的溢出问题。
5. 保留现有认证、RBAC、CSRF、Refresh、二次确认和业务操作能力。

## 非目标

1. 不修改 Backend API 契约和 `@pinjie/api-client`。
2. 不修改既有安全确认流程和 RBAC 权限控制逻辑。
3. 不引入现有 Ant Design 6 与 ProComponents 体系之外的重量级 UI 依赖。

## 现状分析

1. `apps/admin/src/app.tsx` 中侧栏使用深色 Token，Header 操作区层级较弱。
2. `apps/admin/config/defaultSettings.ts` 使用侧栏布局，固定 Header 尚未启用。
3. `UsersPage.tsx`、`AdminsPage.tsx` 和 `RolesPage.tsx` 关闭了 ProTable 原生工具。
4. `apps/admin/src/styles.css` 保留深色侧栏覆盖和分散的页面样式。

## 方案设计

### 1. 布局与主题 Token

- 在 `defaultSettings.ts` 中使用 `navTheme: "light"`、`colorPrimary: "#1677ff"`、`layout: "mix"`、`fixedHeader: true` 和 `fixSiderbar: true`。
- 在 `app.tsx` 中统一浅色 Sider、白色 Header、浅灰工作区、账号菜单和标准 Footer。
- 通过 Ant Design 6 Token 统一圆角、颜色、表头和状态色。

### 2. 页面与 ProTable

- Users、Admins 和 Roles 页面启用 ProTable 的刷新、密度、全屏和列设置。
- 主操作按钮进入 `toolBarRender`，操作列使用轻量链接按钮。
- 保持原有分页、搜索、权限判断、抽屉、弹窗和二次确认行为。

### 3. 全局样式

- 统一页面容器、工作面板、表格、工具栏、登录页和 Footer 样式。
- 删除失效的深色侧栏覆盖。
- 保留受控横向滚动和移动端响应式边界。
