# Admin 登录页多色背景层次优化计划

## 1. 当前状态和结果

- 当前状态：已结束
- 结果：已完成；登录页背景升级为固定的蓝、青、品牌红三色宽幅渐变，Admin typecheck、lint 与 Markdown lint 通过，浏览器验证按用户要求未执行。

## 2. 关联需求

- `BASE-ADMIN-002`：提供管理员登录与权限入口。

## 3. 背景

Admin 登录页背景当前由两层固定线性渐变组成，不包含随机颜色或动画。蓝色和红色装饰层透明度分别仅约 `4%` 和 `2.5%`，实际显示接近纯白，色彩层次不够明显。

## 4. 目标

1. 增加背景中的颜色数量和可见度，让登录页视觉层次更明确。
2. 使用 Ant Design 蓝、青与品牌深红建立统一但有辨识度的配色关系。
3. 保持表单中央区域明亮、文字清晰，并维持 B 端管理工具的克制感。

## 5. 非目标

1. 不加入随机颜色、动态渐变或动画。
2. 不增加装饰色块、独立光球或背景图片。
3. 不修改登录表单、Logo、认证和忘记密码交互。

## 6. 现状分析

- `.login-screen` 使用一层接近白色的蓝色斜向渐变。
- `.login-screen::before` 使用极低透明度的蓝红过渡，视觉贡献很弱。
- 当前背景是固定 CSS，不会因刷新或登录状态随机变化。

## 7. 方案设计

1. 在 `.login-screen` 使用多层线性渐变，分别从左上引入品牌蓝、从中部引入青色、从右下引入品牌深红。
2. 使用宽幅、长距离透明过渡，避免形成离散色块或装饰光球。
3. 保持中央区域接近白色，确保输入框、标题和辅助文案对比度稳定。
4. 提高 `::before` 斜向色带可见度，继续保持静态和不可交互。

## 11. 风险与回滚

- 风险：背景颜色过强可能降低中央表单的文字可读性。
- 控制：只使用低透明度宽幅渐变，并让中央区域保持接近白色。
- 回滚：恢复 `.login-screen` 和伪元素原有两层渐变定义。
