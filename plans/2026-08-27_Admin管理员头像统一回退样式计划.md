## 背景

管理员列表的头像尺寸为 `36px`。当前只有头像字段为空时才传入首字符回退；头像 URL 存在但文件已删除或加载失败时，Ant Design `Avatar` 会切换到空的文字容器，最终显示无内容的深色圆形。顶部账户菜单又使用图标回退，两处表现不一致。

## 目标

- 管理员头像为空或图片加载失败时显示名称首字符。
- 中文名称显示第一个字符，英文名称显示大写首字母。
- 名称无法生成字符时回退到 `UserOutlined`。
- 回退头像使用更浅的主题背景和次级文字色。
- 管理员列表与顶部账户菜单复用同一组件和回退规则。

## 非目标

- 不修改头像上传、删除、存储和缓存逻辑。
- 不修改管理员资料字段或 API 契约。
- 不调整头像尺寸、列表布局、顶部菜单交互和真实头像显示方式。
- 不扩展到用户端 Web 头像组件。

## 现状分析

- 顶部账户菜单头像位于 `apps/admin/src/app.tsx`，使用 `UserOutlined` 回退。
- 管理员列表头像位于 `apps/admin/src/features/admins/AdminsPage.tsx`，已有首字符算法，但只在头像字段为空时渲染文字。
- Ant Design `Avatar` 在图片正常时显示图片，图片加载失败时显示 `children` 或 `icon`；始终传入回退字符即可覆盖失效 URL。
- 两处属于同一管理员身份展示，适合提取到 Admin 公共组件。

## 方案设计

1. 新增公共 `AdminAvatar` 组件，接收管理员名称、账号、头像地址和尺寸。
2. 回退文本从去除首尾空格后的显示名称或用户名提取首个 Unicode 字符，并转换为大写。
3. 始终向 `Avatar` 传入回退文本；真实图片加载成功时仍由 Ant Design 显示图片，空地址或加载失败时显示文字。
4. 回退背景使用 Ant Design `colorFillSecondary`，文字使用 `colorTextSecondary`，保持浅色和主题一致。
5. 顶部账户菜单和管理员列表替换为公共组件，保留现有尺寸、文案、布局和交互。
6. 增加组件测试源码，覆盖中文、英文、空名称和图片失效回退；是否运行 Vitest 继续遵守用户单独授权边界。

## 风险与回滚

- 风险：图片失效事件与文字回退组合不正确时，可能继续出现空圆形或影响正常图片。
- 控制：遵循 Ant Design `Avatar` 的图片与 `children` 回退机制，真实图片仍使用原 `src`；通过类型检查、测试源码和差异复读约束行为。
- 回滚：移除公共组件，恢复顶部图标回退和列表原有头像渲染，不影响数据与接口。
