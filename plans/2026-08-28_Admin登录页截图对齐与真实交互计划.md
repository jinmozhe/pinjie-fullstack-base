## 3. 背景

当前工作区中的 Admin 登录页已经出现接近 Ant Design Pro 的布局，但“自动登录”复选框没有进入提交数据，“忘记密码”链接只阻止默认跳转，第三方登录图标也没有真实认证能力。用户要求直接参考所附截图重新实现，并结合本项目已有功能判断是否提供记住登录与忘记密码。

项目当前使用 HttpOnly Cookie Browser Profile。登录后 Refresh 闲置期限默认 7 天，Session 绝对期限默认 30 天，页面无需保存 Token、密码或额外模拟自动登录。Backend 当前没有登录前自助找回管理员密码端点，只提供已认证且具备权限的管理员重置其他管理员密码。

## 4. 目标

1. 参考截图完成无卡片、居中窄表单、浅色漫射背景和底部版权信息的登录页。
2. 保留“品捷管理系统”项目品牌、现有用户名密码认证、错误反馈、加载状态和登录后跳转。
3. 删除没有真实能力支撑的自动登录复选框和第三方登录方式。
4. 在截图对应的辅助操作位置说明现有安全会话会自动保持，并提供可执行的“忘记密码？”说明弹窗。
5. 保证桌面端与移动端无横向溢出、遮挡和文字溢出，并保持键盘与屏幕阅读器可访问性。

## 5. 非目标

1. 不修改 Backend 登录、Refresh、Cookie 或 Session 契约。
2. 不新增邮件、短信、一次性令牌或登录前自助密码重置流程。
3. 不在 `localStorage`、`sessionStorage` 或客户端状态中保存 Token、密码或 Cookie 内容。
4. 不新增第三方登录方式，不修改 Web 端登录页。

## 6. 现状分析

1. `LoginPage.tsx` 的用户名和密码会提交到 `adminApi.login`，登录成功后更新当前管理员 Query 数据并进入欢迎页。
2. 当前“自动登录”使用未绑定表单字段的 `defaultChecked`，对 Cookie 生命周期和认证结果没有影响。
3. 当前“忘记密码”链接固定阻止默认事件，没有页面、端点或提示承接。
4. 当前支付宝、淘宝和微博图标没有点击逻辑，也没有对应认证端点。
5. `styles.css` 同时包含其他正在进行的 Admin 修改，本计划只精确调整登录页相关选择器，不覆盖无关差异。

## 7. 方案设计

1. **页面构图**：使用全视口浅色背景和低对比度斜向漫射色带，主内容在首屏略高于垂直中心，底部版权固定参与正常布局。
2. **品牌区**：保留项目缩写 `PJ`，以紧凑双色几何标识配合“品捷管理系统”和管理控制台说明，不复制截图中的 Ant Design 品牌。
3. **登录表单**：表单宽度约 `368px`，窄屏使用受控内边距；用户名、密码、密码可见性、错误 Alert 和登录 Loading 继续使用 Ant Design 6 原生组件。
4. **会话说明**：用非交互状态文案表达系统已通过安全 Cookie 自动维持登录，避免用户误以为存在可切换但实际无效的“记住登录”。
5. **忘记密码**：点击“忘记密码？”打开 Ant Design 信息弹窗，明确提示联系有管理员密码重置权限的管理员处理；不承诺尚未实现的自助找回能力。
6. **精简假入口**：移除没有真实端点支撑的 Tabs 单标签结构和第三方登录图标，保留截图的清晰层级与留白。
7. **可访问性**：保留用户名、密码标签语义、Autocomplete、密码长度限制、错误提示和明确按钮名称；弹窗可通过键盘关闭。

## 11. 风险与回滚

- **风险**：当前登录文件和公共样式文件已有未提交修改，整文件覆盖会破坏其他任务内容。
- **控制**：只使用逐块补丁修改登录组件和登录选择器，编辑后复读具体行并检查 `git diff`。
- **风险**：截图对齐可能在移动端造成表单或页脚拥挤。
- **控制**：使用 `min()`、固定最大宽度和窄屏断点控制尺寸，不使用随视口缩放的字体。
- **回滚**：按本计划差异逐块反向应用补丁，不回退工作区中已有的其他修改。
