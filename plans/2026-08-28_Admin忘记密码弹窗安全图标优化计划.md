# Admin 忘记密码弹窗安全图标优化计划

## 1. 当前状态和结果

- 当前状态：已结束
- 结果：已完成；忘记密码弹窗增加 Ant Design 双色安全徽章并移除文本表情，Admin typecheck、lint 与 Markdown lint 通过，浏览器验证按用户要求未执行。

## 2. 关联需求

- `BASE-ADMIN-002`：提供管理员登录与权限入口。

## 3. 背景

登录页忘记密码弹窗当前使用纯文本“请联系超级管理员为您重置密码 ^_^”。用户希望提升人性化与安全感，并确认采用 Ant Design 彩色安全图标方案。

## 4. 目标

1. 使用 Ant Design `SafetyCertificateTwoTone` 强化安全重置语义。
2. 使用主蓝和浅蓝双色，保持与管理端视觉体系一致。
3. 移除文本表情，将情绪表达交给图标和版式。

## 5. 非目标

1. 不增加密码找回、邮件或手机验证能力。
2. 不修改弹窗标题、按钮和打开关闭逻辑。
3. 不制作自定义 SVG、位图或动画。

## 6. 现状分析

- 弹窗由 Ant Design `Modal` 呈现。
- 正文当前只有 `.login-recovery-copy` 段落样式。
- 项目已安装并使用 `@ant-design/icons`，无需增加依赖。

## 7. 方案设计

1. 导入 `SafetyCertificateTwoTone`，使用 `#1677FF` 与 `#BAE0FF` 双色配置。
2. 在正文上方增加 `56px` 浅蓝圆形图标容器，图标尺寸为 `30px`。
3. 弹窗内容采用居中 Grid 布局，图标与正文间距为 `12px`。
4. 正文调整为“请联系超级管理员为您重置密码”，移除 `^_^`。
5. 图标标记为装饰元素，文字继续承担完整语义。
